# YORE | Wear It Yore Way

A responsive T-shirt online store developed for **MMS 142: Internet Technologies and Web Development** at the **University of the Philippines Open University**.

## About the Project

YORE is an online T-shirt store designed to provide customers with a simple and convenient shopping experience. It features three specially designed T-shirt products, a contact page, and an About page that includes the Privacy Policy and the Terms and Conditions.

This project continues the website planning and wireframing completed in Assignment #1.

## Products

- Don't Be Late Tee
- Everyday Comfort Tee
- Do Good Work Tee

## Website Pages

| Page | File | Description |
|---|---|---|
| **Home** | `index.html` | Introduces YORE and showcases the available products. |
| **Shop (Product Pages)** | `dont-be-late/`, `everyday-comfort/`, `do-good-work/` | Displays product information and provides an **Order Now** option. The Shop link opens the Don't Be Late Tee first, and **View other shirts** leads to the other two. |
| **About** | `Privacy Policy/privacy-policy.html` | Where the **Privacy Policy** and the **Terms and Conditions** are placed. It explains the website's privacy practices and store terms. |
| **Contact Us** | `Contact/contact.html` | Allows customers to send inquiries. |
