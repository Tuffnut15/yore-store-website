# YORE | Wear it Yore Way.

A responsive T-shirt online store developed for **MMS 142: Internet Technologies and Web Development** at the University of the Philippines Open University.

## About the Project

YORE is an online T-shirt store designed to provide customers with a simple and convenient shopping experience. It features three specially designed T-shirt products, a contact page, and a privacy policy page.

This project continues the website planning and wireframing completed in Assignment #1.

## Products

- Don't Be Late Tee
- Everyday Comfort Tee
- Do Good Work Tee

## Website Pages

- Home: Introduces YORE and showcases the available products.
- Contact Us: Allows customers to send inquiries.
- Privacy Policy: Explains the website's privacy practices.
- Product Pages: Displays product information and provides an Order Now option.
